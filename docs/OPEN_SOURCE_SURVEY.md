# 开源“双色球/彩票深度学习预测”项目生态调研报告

> **调研时间**：2026-10-16  
> **调研对象**：GitHub、开源社区及相关学术探讨中关于双色球（SSQ）/彩票（Lottery）的 AI 与机器学习项目

---

## 1. 开源生态现状全景

在 GitHub 和开源社区中，“彩票预测（双色球、大乐透）”一直是一个具有**极高热度、极高娱乐性与强练手属性**的经典课题。

程序员开源此类项目的两大核心动机：
1. **技术练兵（正经目的）**：用最简单、直观且充满悬念的离散数据，完整演练一次：
   - Web 爬虫（Requests/BeautifulSoup/Selenium）；
   - 数据工程（Pandas、独热编码、遗漏值矩阵）；
   - 深度学习框架（PyTorch/TensorFlow/Keras）；
   - 时序模型（LSTM/GRU/Transformer）；
   - 前端报表与工程化部署（Streamlit/Docker/FastAPI）。
2. **赛博整活（娱乐目的）**：不少开发者在 README 中自嘲“主打一手赛博炼丹与玄学”，甚至将周易八卦、量子力学与 PyTorch 混编。

---

## 2. GitHub 上的四大主流技术流派

### 流派一：纯循环神经网络派 (LSTM / GRU / RNN)
* **代表项目**：
  - `yinqishuo/Bicolorballs-AI` (TensorFlow/Keras LSTM)
  - `piggyone/chromosphere` (LSTM+RNN 时序建模)
  - `gsxhnd/Lottery` (PyTorch LSTM 实验)
  - `Liang-yc/ssq` (老牌双色球/大乐透机器学习预测库)
* **核心思路**：把前 $N$ 期的开奖号码转化为 One-Hot 序列或浮点张量，直接丢进 LSTM，尝试让模型捕捉“走势规律”。
* **开源作者的真实结论**：
  > 绝大多数作者在训练了几百个 Epoch 后，都会在 README 里无奈坦白：  
  > *“测试集平均命中红球数稳定在 0~2 个，与纯随机瞎蒙没有统计学差异。项目主要用于深度学习框架 API 练习，切勿当真。”*

### 流派二：传统彩票统计学 + 组合过滤缩水派 (Heuristic & Filter)
* **代表项目**：
  - `zxz0119/lottery-ai-simulator` (多彩种模拟器，带可视化看板)
  - `carpenterma7/lottery_easy` (融合多种统计、贝叶斯与旋转矩阵算法)
* **核心思路**：不依赖黑盒神经网络，而是使用扎实的概率统计学：
  - 冷热号加权采样、遗漏期数周期律；
  - 旋转矩阵（Wheel System，如“保5中4”、“保6中5”缩水软件原理）；
  - 和值（Sum）、奇偶比、质合比、连号过滤。
* **效果评价**：虽然也不能保证中大奖，但它成功剔除了大量极低概率的反常垃圾组合（例如 01,02,03,04,05,06 或全偶数组合），在**实际投注形态合理性**上显著优于纯 LSTM。

### 流派三：现代生成式模型派 (Transformer / VAE / Diffusion)
* **代表项目**：部分高阶开发者尝试使用小型 Transformer（类似 nanoGPT）或条件变分自编码器（CVAE）。
* **核心思路**：
  - 将红球看成词表（Token 1~33），开奖视作有序自回归文本：`[BOS, R1, R2, R3, R4, R5, R6, Blue, EOS]`；
  - 或者利用 VAE 学习真实中奖号码的高维流形分布，从隐空间采样。
* **效果评价**：生成的号码符合“号码不重复、单调递增、蓝球独立”的逻辑语法约束，比全连接回归优雅得多。

### 流派四：AI Agent 时代的新流派 (LLM / Claude / Cursor Skills)
* **最新趋势**：近期社区出现了多款适配 Claude Code / Cursor / DeepSeek 的彩票分析插件或 Prompt Agent。
* **核心思路**：Agent 自动调用爬虫 API 抓取近 20 期数据，然后调用大模型对近期的遗漏走势、连号形态进行“专家式深度复盘”，并输出今日机选方案。

## 3. 开源生态给我们的核心启发（如何做一个更优秀的项目？）

从已有的开源项目失败教训和成功经验中，我们可以提炼出本项目（`SSQ-Prediction-AI`）的**降维打击式架构设计**：

| 维度 | 传统开源项目的缺陷 | 本项目的设计方案 |
| :--- | :--- | :--- |
| **模型设计** | 盲目堆叠普通 LSTM，硬拟合随机白噪声 | 采用 **TCN 时间因果卷积 + 双塔多任务（红球BCE + 蓝球CE）**，只预测概率分布而非死数字 |
| **特征工程** | 只给模型输入简单的历史开奖数字 | 注入**彩票统计物理特征**：实时遗漏矩阵（Omission Gap）、冷热频次、滚动和值、奇偶特征 |
| **后处理机制** | 模型直接输出 6 个数字，经常出现重复球或极端形态 | **双层漏斗过滤机制**：模型生成 10,000 注概率采样池 $\to$ 专家规则过滤器（剔除极端和值、全奇偶、4连号） $\to$ 最终精选 |
| **闭环验证** | 只有训练 Loss，不知道到底赚还是亏 | 引入**金融量化级历史模拟回测（Backtesting）**：模拟过去 100 期按该系统选号的中奖率与资金返还率 |
