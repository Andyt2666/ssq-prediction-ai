# 双色球（SSQ）深度学习选号与统计实验系统 (SSQ-Prediction-AI)

> 📢 **科学定位与理性声明**：这是一个**严肃的数据科学、概率论与深度学习工程实验开源项目**。  
> 双色球每期开奖在物理与数学本质上是**严格独立同分布（i.i.d.）的随机事件**，开奖机制绝不依赖任何历史数据。  
> 本项目的目标**绝不是**为了“提高中奖概率”，而是为了搭建一套完整、严谨且可复现的工业级流水线，并给出诚实的科学评估结论：**深度学习模型相对均匀随机基线无统计学显著差异**。

---

## 1. 核心流水线架构

```text
数据采集 (500.com) ──> 清洗入库 (SQLite/CSV) ──> 特征工程 (遗漏/和值/AC值) ──> 深度学习模型 (TCN / ST-GNN) ──> 概率分布
                                                                                                                │
                                                                                                                ▼
报告图表 (reports/) <── 历史滚动回测 (Walk-Forward) + 1000次蒙特卡洛随机基线 <── 规则过滤缩水 <── 候选采样 (8k注, τ温度)
                                                                                  (和值/奇偶/多样性)
```

### 缩水过滤的真实价值：
缩水过滤**不会也不可能**提高任何单注的中奖概率（每一注的数学中奖概率恒定为 $\frac{1}{17,721,088}$）。它的实际价值在于：
1. **形态正常化**：过滤掉反常的极端组合（如全奇全偶、连续 4 连号、极低和值等历史上几乎从不出现的极端形态）；
2. **避开大众扎堆号**：避开生日号（全部 $\le 31$）、纯等差数列，从而在中奖时大幅减少与他人分奖的可能。

## 3. 命令行快速使用 (CLI Guide)

系统已封装标准 CLI 命令，直接在虚拟环境中调用：

```bash
# 激活环境
source .venv/bin/activate

# 1. 数据采集与统计学随机性检验 (阶段 0)
python main.py fetch

# 2. 训练基础 TCN 因果卷积深度学习模型 (阶段 2)
python main.py train --epochs 25

# 3. 训练复杂 ST-GNN-Vision 多拓扑时空图网络
python main.py train_stgnn --epochs 25

# 4. 执行 AI 采样与智能缩水推荐 (阶段 3 & 5)
python main.py predict --num 5            # 使用 TCN 模型
python main.py predict_stgnn --num 5      # 使用 ST-GNN 走势图模型

# 5. 运行严格时间前向滚动回测与蒙特卡洛对照 (阶段 4)
python main.py backtest --issues 100
python main.py backtest_stgnn --issues 100
```

## 4. 阶段 0 随机性检验与数理统计结论

我们在 3500 余期历史真实数据上执行了完整的数理统计检验：
1. **红球卡方拟合优度检验**：$\chi^2 = 44.73 < 46.19$ (自由度 32, $\alpha=0.05$)，**无法拒绝均匀分布原假设**；
2. **蓝球卡方拟合优度检验**：$\chi^2 = 8.83 < 24.99$ (自由度 15, $\alpha=0.05$)，**无法拒绝均匀分布原假设**；
3. **蓝球奇偶独立性游程检验**：$|Z| = 0.145 < 1.96$，**开奖序列无记忆粘性**；
4. **和值滞后自相关系数**：Lag-1, Lag-2, Lag-3 相关系数均在 $\pm 0.03$ 随机涨落范围内。

> **结论**：双色球是一套极其标准的物理随机系统，历史数据不具备任何对未来的指向性。任何模型获得的拟合损失降低均属于对白噪声的微弱样本内拟合。
